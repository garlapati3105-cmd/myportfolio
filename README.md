## ✨ Features & Visual Highlights

- **🧠 Agent Reasoning Console**: Located in the Hero section, a fully simulated terminal that visualizes live reasoning paths of an autonomous agent completing tasks in real-time.
- **🕸️ Neural Network Particle Canvas**: An interactive, customized canvas background (`BackgroundEffect.jsx`) representing connected nodes that react smoothly to pointer movements.
- **🚀 Project Showcase Hub**: Clickable cards linking directly to Saikiran's major open-source repositories:
  - **Autodebug Agent**: An AI-powered code analysis and automated debugging companion.
  - **Resume Builder**: A smart builder to compile professional resumes from structured prompts.
  - **AI News Summarizer**: A content aggregator that reads, digests, and summarizes tech and AI news.
  - **Interview AI**: An interactive, voice/text simulation partner for preparing technical interviews.
- **📜 Verified Certifications Drawer**: Fully interactive cards linking directly to official credentials and verifications:
  - **NIAT AI Agents Certification** (CCBP Beta Program)
  - **Advanced AI-AGENTS-NIAT Certification**
  - **NIAT Base 44 Certification**
- **📬 Dynamic Contact Terminal**: Built-in email interface with telemetry indicators, simulation states, and interactive quick-connect channels via LinkedIn and direct email.

## 🚀 Local Quickstart

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### 1. Clone the repository
```bash
git clone https://github.com/garlapati3105-cmd/myportfolio.git
cd myportfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the local development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```
The output directory will be `dist/`, optimized and ready for static hosting services (like Vercel, Netlify, or GitHub Pages).
